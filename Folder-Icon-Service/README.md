# 🗂️ Folder Icon Service

Честно говоря, я запарился с этим проектом, но оно того стоило! Теперь у меня каждая папка выглядит так, как я хочу. Если у тебя куча папок и ты в них путаешься — это решение для тебя.

## 📌 Что это вообще такое?

Это служба Windows, которая автоматически назначает кастомные иконки для папок. Она просто создает скрытый файл `desktop.ini` в нужных папках и говорит Windows, какую иконку показывать.

**Почему я выбрал этот способ:**  
Потому что вариант с Shell Extension — это жесть, нужно писать на C++, разбираться с COM-интерфейсами, а тут все просто и работает без перезапуска проводника.

---

## ⚙️ Как это настроить

### 1. Установка службы

Открываешь командную строку **от имени администратора** (это важно, иначе будет ругаться) и выполняешь:

> Привожу пути своей системы, для себя нужно заранее продумать пути где будет проект и заменить - тут чисто для сравнения.

```cmd
cd /d D:\Windows-Services\Folder-Icon-Service\bin\Debug
sc create FolderIconService binPath= "D:\Windows-Services\Folder-Icon-Service\bin\Debug\Folder-Icon-Service.exe" DisplayName= "Служба иконок папок" start= auto
net start FolderIconService
```

После этого служба будет автоматически запускаться при старте Windows. Удобно, не надо каждый раз запускать руками.

### 2. Настройка иконок

В папке со службой (где лежит `Folder-Icon-Service.exe`) есть файл `FolderIcons.config`. Открываешь его блокнотом и пишешь пары:

> Сейчас там одна пара, чисто для проверки, добавляешь сколько нужно тебе с каждой новой строки новую пару.

```
путь_к_папке|путь_к_иконке
путь_к_папке|путь_к_иконке
```

**Пример:**
```
C:\Users\elf\Desktop\Fortecya|C:\Users\elf\Downloads\pokedex.ico
D:\МоиПроекты|C:\Windows\System32\imageres.dll,3
```

**Важно:** каждая пара на новой строке, разделитель — вертикальная палка `|`.

### 3. Если иконка не отображается 🤦

Эту херню я прошел на своем опыте. Чаще всего проблема в правах доступа. Служба запускается от имени `SYSTEM`, а у него тупо нет прав писать в твою папку. Лечится просто:

```cmd
icacls "C:\Users\elf\Desktop\Fortecya" /grant SYSTEM:F /t
```

Это дает системе полный доступ к папке. Перезапускаешь службу:

```cmd
net stop FolderIconService
net start FolderIconService
```

Ждешь 30 секунд (там таймер стоит) и проверяешь папку.

### 4. Обновление кэша иконок

Если иконка не появилась даже после всех плясок с бубном, обнови кэш:

```cmd
ie4uinit.exe -show
```

Или просто перезапусти проводник через диспетчер задач. Это помогает в 90% случаев.

## 📁 Поддерживаемые форматы иконок

- **ICO** — самый надежный вариант. Иконки работают всегда.
- **DLL** — можно использовать системные иконки из `imageres.dll` или `shell32.dll`, указывая индекс через запятую. Пример: `C:\Windows\System32\imageres.dll,3`
- **SVG, PNG** — НЕ РАБОТАЮТ! Я тоже пробовал, но Windows тупо игнорит. Если у тебя SVG, сначала сконвертируй в ICO любым онлайн-конвертером.

## 🐛 Мои грабли (и как я их пережил)

**1. Кириллица в путях**  
Я сначала использовал `D:\ФОТО` и думал, что проблема в кириллице. Оказалось, нет — проблема была в правах доступа. Служба не могла записать `desktop.ini`. После того как я дал права SYSTEM на папку (`icacls /grant SYSTEM:F`), все заработало, даже с русскими буквами в пути. Так что кириллица — не проблема.

**2. SVG не работает**  
Этого я не знал сначала. Думал, что любая иконка подойдет. А нет — только ICO. Если у тебя PNG или SVG, конвертируй, не трать время.

**3. Не отображается в services.msc**  
Служба создается через `sc create`, но в оснастке может не появляться сразу. Просто перезагрузи комп или управляй через командную строку. Я так и делаю, привык.

**4. Служба не запускается с ошибкой 1053**  
Это значит, что служба не отвечает. Проверь, существует ли файл `Folder-Icon-Service.exe` в папке. У меня такая ошибка была, когда я переименовал исполняемый файл.

## 💡 Советы по оптимизации

1. **Дай права на все нужные папки заранее.** Если у тебя папки в разных местах, выполни `icacls` для каждой из них.

2. **Перезапускай службу после изменения конфига.** Она проверяет файл раз в 30 секунд, но лучше дернуть вручную.

3. **Используй системные иконки для быстрых тестов.** Если не уверен в своем ICO, попробуй сначала `imageres.dll,3` — это стандартная иконка папки. Если она работает, значит проблема в твоей иконке.

4. **Создай батник для установки.** У меня есть такой на случай переустановки системы:
```batch
sc create FolderIconService binPath= "D:\Windows-Services\Folder-Icon-Service\bin\Debug\Folder-Icon-Service.exe" DisplayName= "Служба иконок папок" start= auto
net start FolderIconService
```
